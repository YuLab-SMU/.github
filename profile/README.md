### YuLab @ Southern Medical University

We are a bioinformatics group at the [School of Basic Medical Sciences, Southern Medical University](https://yulab-smu.top) (Guangzhou, China). We develop methods and open-source software that help biologists explore, interpret and communicate their data — from functional enrichment to phylogenetic trees, from single-cell atlases to AI-native analysis in R.

Our packages are distributed mainly via **Bioconductor** and **CRAN**, and are designed to work together: the same data structures, the same grammar of graphics, the same reproducible workflow.

## Research areas

### 1. Biological Knowledge Mining

Statistical methods and software for interpreting omics data: functional enrichment, semantic similarity, and knowledge-based annotation.

+ [clusterProfiler](https://github.com/YuLab-SMU/clusterProfiler) — universal enrichment analysis for gene lists and gene clusters, now extended to single-cell and spatial data
+ [enrichplot](https://github.com/YuLab-SMU/enrichplot) — visualization of functional enrichment results
+ [DOSE](https://github.com/YuLab-SMU/DOSE) — Disease Ontology semantic and enrichment analysis
+ [GOSemSim](https://github.com/YuLab-SMU/GOSemSim) — semantic similarity measures among GO terms, gene products and gene clusters
+ [ChIPseeker](https://github.com/YuLab-SMU/ChIPseeker) — ChIP peak annotation, comparison and visualization
+ [ReactomePA](https://github.com/YuLab-SMU/ReactomePA) · [meshes](https://github.com/YuLab-SMU/meshes) · [gson](https://github.com/YuLab-SMU/gson) · [HDO.db](https://github.com/YuLab-SMU/HDO.db) · [createKEGGdb](https://github.com/YuLab-SMU/createKEGGdb)

### 2. Data Visualization

Grammar-of-graphics extensions for the data types biologists actually work with — plots, trees, sequences, genomes, networks, and maps.

+ [aplot](https://github.com/YuLab-SMU/aplot) — align and combine plots with shared axes
+ [ggimage](https://github.com/YuLab-SMU/ggimage) — use images in ggplot2
+ [ggbreak](https://github.com/YuLab-SMU/ggbreak) — axis breaks for `ggplot2`
+ [ggmsa](https://github.com/YuLab-SMU/ggmsa) — publication-quality multiple sequence alignment
+ [plotbb](https://github.com/YuLab-SMU/plotbb) — grammar of graphics on base graphics
+ [ggsc](https://github.com/YuLab-SMU/ggsc) — visualizing single-cell and spatial transcriptomics
+ [ggfun](https://github.com/YuLab-SMU/ggfun) · [ggtangle](https://github.com/YuLab-SMU/ggtangle) · [scatterpie](https://github.com/YuLab-SMU/scatterpie)

### 3. Phylogenetic Data Integration

A programmable environment for handling tree-structured biological data: parsing, integrating, manipulating and visualizing phylogenetic trees together with their associated data.

+ [ggtree](https://github.com/YuLab-SMU/ggtree) — visualization and annotation of phylogenetic trees
+ [treeio](https://github.com/YuLab-SMU/treeio) — base classes and functions for phylogenetic tree input and output
+ [tidytree](https://github.com/YuLab-SMU/tidytree) — tidy manipulation of phylogenetic tree data
+ [ggtreeExtra](https://github.com/YuLab-SMU/ggtreeExtra) — add geom layers on circular or other layout trees
+ [treelayout](https://github.com/YuLab-SMU/treelayout) — tree layout algorithms (node coordinates), extracted from ggtree
+ [ggtreeDendro](https://github.com/YuLab-SMU/ggtreeDendro) — drawing dendrograms with ggtree

### 4. AI-Native Scientific Computing

AI-native infrastructure for scientific computing in R. This is our newest direction: making AI-assisted data analysis **programmable, auditable and reproducible**, rather than a chat window beside the analysis.

+ [aisdk](https://github.com/YuLab-SMU/aisdk) — a unified runtime for model providers, tool calling, agents, skills, channels and image generation in R
+ [ggai](https://github.com/YuLab-SMU/ggai) — grammar-guided AI visualization: from natural-language intent to reproducible scientific figures
+ [Rho](https://github.com/YuLab-SMU/Rho) — an agent-native desktop workbench for R
+ [sclet](https://github.com/YuLab-SMU/sclet) — state-aware toolkit for single-cell and spatial transcriptomics
